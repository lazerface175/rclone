rclone on NAS

Quick reference for running rclone on a headless NAS.

1. Install

# Debian / Ubuntu
curl https://rclone.org/install.sh | sudo bash

# or via package manager
sudo apt install rclone   # may be outdated; prefer install.sh

2. Configure remotes

rclone config        # interactive wizard
rclone listremotes   # verify

3. Mount / serve

# mount a remote locally
rclone mount remote: ~/mnt/remote --daemon

# serve over webdav / http / sftp / etc.
rclone serve webdav remote: --addr :8080

4. Keep it running

# systemd user service example
systemctl --user enable --now rclone-mount.service

See the rclone docs for backend-specific setup (Drive, S3, SFTP, etc.).
